Step 3 / Publish with GitHub

  1. Sign in to Samantha-Hannah-Wynne on GitHub.
  2. Upload both WebP files to the prints folder ↗ and commit them.
  3. Open the downloaded gallery-card text and copy it.
  4. Edit the studio home page on GitHub ↗, search for OWNER PHOTO CARDS, paste the card immediately above that marker, then commit.
  5. GitHub Pages will rebuild the website automatically. Refresh the gallery after about a minute.

Only publish your own photos. Check the title, description and alt text before committing. Never paste a GitHub password or access token into this page.
